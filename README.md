# 🩺 Multi-Disease Prediction System

A machine learning web application built to predict the risk of multiple diseases (**Diabetes, Heart Disease, and Breast Cancer**) using structured medical data from the UCI Machine Learning Repository.

## 🚀 Features
* **Multiple Datasets:** Integrates Pima Indians Diabetes, Cleveland Heart Disease, and UCI Wisconsin Breast Cancer datasets[cite: 1].
* **Classification Algorithms:** Trains and compares **SVM, Logistic Regression, Random Forest, and XGBoost** models[cite: 1].
* **Interactive UI:** Built with **Streamlit** to allow users to input clinical measurements and get real-time risk predictions along with confidence probabilities[cite: 1].
* **Model Evaluation:** Provides performance comparison metrics (Accuracy, Precision, Recall, F1-Score, and ROC-AUC) and confusion matrices[cite: 1].

---

## 🛠️ Tech Stack
* **Python** (3.8+)
* **Scikit-Learn** & **XGBoost** (Machine Learning models & pipelines)
* **Streamlit** (Web dashboard interface)
* **Pandas & NumPy** (Data manipulation)
* **Matplotlib & Seaborn** (Data visualization)
